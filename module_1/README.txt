# Module 1 - Personal Developer Website

This project is a personal developer website built using Flask, HTML, and CSS.

## Requirements

- Python 3.10 or higher
- Flask

## How to Run

1. Activate the virtual environment:

   `source yourappenv/bin/activate`

2. Install the required packages:

   `pip install -r requirements.txt`

3. Start the Flask application:

   `python run.py`

4. Open the following address in a web browser:

   `http://127.0.0.1:8080`
